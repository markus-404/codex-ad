# Platform Presets

Use platform presets when the user names a channel, placement, or goal instead
of a raw aspect ratio. The preset supplies the default ratio, layout guidance,
creative style, and copy density.

## Presets

- `meta-feed-conversion`: 4:5 product-forward conversion ad for Meta feed.
- `instagram-story`: 9:16 vertical story ad with safe-zone constraints.
- `square-retargeting`: 1:1 product and offer reminder for warm audiences.
- `tiktok-static`: 9:16 UGC-style static frame with native social context.
- `linkedin-lead-gen`: 1:1 clean B2B lead-generation layout.

When the user does not specify a platform, default to `meta-feed-conversion` for
consumer conversion offers and `linkedin-lead-gen` for B2B lead-generation
offers.
