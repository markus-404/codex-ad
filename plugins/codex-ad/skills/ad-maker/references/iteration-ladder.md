# Iteration Ladder

Use this ladder when turning one winning ad into new static ad concepts.

1. Analyze the original ad and summarize visual hook, offer, audience, proof, product role, and performance notes.
2. Generate 3 strategy directions:
   - Create alternate versions
   - Iterate messaging
   - Add floating callouts or pop-ups
3. Generate 4 named ad ideas per strategy.
4. For each ad idea, include name, scene, persona target, rationale, key message, emotion, and theme.
5. Compile selected ad ideas into the six-slot prompt template.
6. Generate variants using the requested ratio and variant count.
